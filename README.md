# İlk Uygulamam - Başlangıç Seviyesi Ekran

Bu proje, Kotlin ile yazılmış basit bir Android uygulamasıdır. İlk uygulamam olarak geliştirdiğim bu proje, başlangıç seviyesinde temel Android uygulama geliştirme kavramlarını öğrenmek amacıyla oluşturulmuştur.

## Özellikler
- **Kotlin ile geliştirilmiştir:** Uygulamanın tamamı Kotlin dilinde yazılmıştır.
- **Basit Arayüz:** Kullanıcı dostu, başlangıç seviyesinde tasarlanmış bir ekran sunar.
- **Öğrenme Amacı:** Android geliştirme ve temel konseptler hakkında pratik yapma imkanı sağlar.
